# Coffee Dragon Clicker - Godot 4.x версия

## 🎮 Описание
Кликер-игра с драконом и кофейней, перенесенная на движок Godot 4.x.

## 📁 Структура проекта
```
godot_coffee_clicker/
├── project.godot          # Конфигурация проекта
├── icon.svg               # Иконка проекта
├── scenes/
│   └── main.tscn          # Главная сцена игры
├── scripts/
│   ├── main.gd            # Главный скрипт сцены
│   ├── game_state.gd      # Состояние игры и данные
│   ├── game_manager.gd    # Логика игры
│   └── ui_manager.gd      # Управление интерфейсом
└── assets/
    ├── sprites/           # Спрайты (дракон, зерна)
    └── fonts/             # Шрифты
```

## 🚀 Запуск игры

1. Откройте Godot 4.x (рекомендуется 4.3+)
2. Нажмите "Import" и выберите файл `project.godot`
3. Нажмите F5 или кнопку Play для запуска

## 🎯 Геймплей

### Основное
- **Кликайте по дракону** (мышкой или пробелом) для сбора зёрен
- Каждое действие дает очки активности
- Зёрна используются для покупки улучшений

### Улучшения плантации
| Улучшение | Эффект |
|-----------|--------|
| 👆 Улучшенный клик | +1 зерно за клик |
| ⚙️ Кофемолка | 1 зерно/сек |
| 🤖 Авто-сборщик | 5 зёрен/сек |
| 🌿 Плантация | 25 зёрен/сек |
| 🔥 Жертва | Шанс бонуса |
| ✨ Благословение | Глобальный бонус |
| 🐉 Эволюция | Развитие дракона |
| 🎁 Подарок дракону | Дружба с драконом |

### Кофейня
- Варите кофе из зёрен
- Получайте дракоинсы 💰
- Покупайте улучшения кофейни
- Открывайте новые страницы напитков

#### Напитки
**Страница 1: Основные**
- Эспрессо, Американо, Капучино, Латте, Моккачино

**Страница 2: Премиум**
- Флэт Уайт, Кортадо, Раф

**Страница 3: Экзотические**
- Глясе, Айс Латте, Фраппе

**Страница 4: Легендарные**
- Ирландский, Ристретто, Доппио

## 🎮 Управление

| Действие | Управление |
|----------|------------|
| Клик по дракону | ЛКМ / Пробел |
| Переключение вкладок | Кнопки внизу экрана |
| Покупка улучшений | Кнопка "Купить" |
| Приготовление кофе | Кнопка "Приготовить" |

## 💾 Сохранение

Игра автоматически сохраняется:
- Каждые 2 минуты игрового времени
- При выходе из игры (вручную через кнопку)

Файл сохранения: `user://savegame.json`

## 🔧 Технические детали

### Версии
- **Godot**: 4.3+ (совместимо с 4.x)
- **Язык**: GDScript
- **Рендерер**: Forward Plus
- **Разрешение**: 1920x1080 (Full HD)

### Особенности реализации
- **Масштабируемость**: UI адаптируется под разрешение экрана
- **Сигналы**: Использование сигналов Godot для связи между узлами
- **Автосохранение**: Таймеры для периодического сохранения
- **Эффекты**: Tween-анимации для кликов и переходов

## 📝 Отличия от веб-версии

1. **Упрощенная система достижений** - базовая реализация
2. **Без Firebase** - локальное сохранение
3. **Без лидерборда** - офлайн-режим
4. **Без регистрации** - игра начинается сразу
5. **Упрощенные анимации** - базовые эффекты

## 🛠 Расширение

Для добавления нового контента:

### Новые улучшения
```gdscript
# В game_state.gd добавьте в upgrades:
"upgrade_new": {"level": 0, "cost": 1000, "max_level": 10, "type": "special"}
```

### Новые напитки
```gdscript
# В game_state.gd добавьте в get_drink_data():
15: {"name": "Новый напиток", "base_bean_cost": 100, "base_dracoins": 200, "duration": 5000, "page": 2}
```

### Новые достижения
```gdscript
# В game_state.gd добавьте в achievements:
new_achievement: false
```
